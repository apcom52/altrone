# Dark Theme

- Theme state is JS (data attribute), not `prefers-color-scheme` alone — matches the next-themes/Radix Themes convention. Keep this approach.
- Only `data-altrone-theme` is used (set on the root `data-altrone-root` element via React, and on `<html>` via `useLayoutEffect` for global/portal styles). The legacy `.AltroneDark` class selector doesn't exist — don't reintroduce it.
- When writing dark-mode CSS, use real tokens (`--text-*`, `--background-*`, `--interactive-*`, `--accent-N`, `--danger-text-1`, `--disabled-text-color`, etc.). Watch out for Tailwind-scale names (`--default-N`, `--primary-N`, `--danger-N` as 50-900) — they only exist in `application/index.css`, which is never imported anywhere; using them silently no-ops in both themes.
- FOUC prevention: `getThemeInitScript(initialTheme)` (`application/getThemeInitScript.ts`) — `Application` renders it inline before the tree paints (mirrors `resolveInitialTheme`: explicit `theme` prop wins, `'auto'` resolves via `matchMedia`). Best-effort only; a consumer needing a hard SSR guarantee should render it themselves in their own document `<head>`.
- Key dark-mode token values: `--glass-background-color` → `--gray-a6` (glass surfaces need a light-tinted alpha over blur, not a darker patch — affects Modal/Drawer/Tooltip's button/Tabs.Item/NavigationList/Toolbar/DataTable header/Box's `glass` material); `--color-overlay-scrim` → `--black-a7` (modal/drawer/screen backdrops); `--tooltip-background-color` → `--gray-6` (Tooltip has no border/shadow, so it lightens the fill instead — `--tooltip-arrow-color` tracks it).
- **Decided: not adopting `light-dark()`/`color-scheme`** — rewriting every color file onto it was judged too risky for an architectural win with no functional benefit. Don't re-propose without new information.
- `getThemeInitScript` and the `Theme`/`Accent`/`Language` types are exported from the public API (`application/index.ts`).
- See `application/styles/DarkTheme.stories.tsx` (Storybook `Foundations/Dark Theme`) for a live theme-toggle demo.
