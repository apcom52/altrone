# Border Radius — Concentric Radius Formula

- Formula: `radius_child = radius_parent - gap`.
- **Floor, with a trust-the-author escape hatch**: the result is floored at `var(--radius-mini)` (2px) so a wide gap never rounds a corner all the way down to a hard, square edge inside an otherwise-rounded container. But if the parent's radius is itself already at or below that floor — most notably an explicit `--radius-outer: 0` ("no radius") — the floor does **not** apply and the value passes through unchanged. Implementation: `clamp(var(--radius-mini), calc(var(--radius-outer) - gap), var(--radius-outer))`. `clamp(MIN, VAL, MAX)` is specified to resolve to `MAX` whenever `MIN > MAX`; since `MAX` here is the inherited (un-subtracted) radius, that case fires exactly when the inherited radius is below the floor, which is what makes "explicitly 0 stays 0" work without extra conditional logic.
- Precedents: shadcn/ui (all `--radius` tiers computed via `calc()` from one root value), Apple SwiftUI `ContainerRelativeShape` (child dynamically asks the container for its shape).
- **Decided**: implement via CSS `calc()`/`clamp()` from inherited custom properties (`var(--radius-outer)`, gap value) — do not author a parallel static radius-by-size table, or we reproduce the same source-of-truth drift currently being fixed in spacing.
- CSS custom property inheritance is the web equivalent of `ContainerRelativeShape`: the child reads the parent's `var(--radius-outer)` through the cascade, no JS, cheap (resolved at style recalculation).
- To animate radius through a transition, register it via CSS Houdini `@property` (`syntax: '<length>'`) — a plain custom property animates as a string (discretely), not as a length.
- Reference implementation: `core/src/components/application/styles/_radius.scss` (tokens) and `core/src/components/application/styles/Radius.stories.tsx` (live playground + rationale), `core/src/components/pagination/pagination.module.scss` (first real adopter).
