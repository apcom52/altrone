## `info` больше не фиксированный синий — следует за accent

В T-167 статус `info` был реализован как фиксированный хью (`blue`), по аналогии с `danger`/`success`/`warning`. По уточнению — это неверно для `info`: теперь `--info-*` алиасится на `--accent-N` напрямую, а не на `--blue-N`, и меняется вместе с выбранным `accent` потребителя. `danger`/`success`/`warning` остаются фиксированными без изменений.

Зачем: `info` — про привлечение внимания в рамках основного (акцентного) флоу приложения, а не про универсальное состояние вроде ошибки/успеха/предупреждения, которое обязано оставаться узнаваемым независимо от брендинга. Часть архитектурного рефакторинга v4 (`.claude/rules/color.md`), Linear T-167.

## Уточнена спецификация Box: проп shape

`Box` (T-173) ещё не реализован в коде — это правка спецификации (`.claude/rules/box.md`) перед реализацией. Проп `shape` определён как `rect | squircle | rounded | circle` (было в черновике `square | rounded | capsule | circle`). Величина скругления по-прежнему берётся из `radius` (`--radius-outer`, concentric radius из T-164) — `shape` задаёт только форму угла: `rect` форсирует радиус в 0, `rounded` — обычный `border-radius`, `squircle` — тот же радиус через CSS `corner-shape: squircle` с фолбеком на `rounded` через `@supports` (не JS-детект), `circle` — `border-radius: 50%`, radius не применяется.

Зачем: фиксирует решение по форме `Box` до начала реализации, чтобы T-173 стартовала с согласованной спецификацией. Linear T-173.

## Инфраструктура reduced motion

Три слоя из `.claude/rules/motion.md` реализованы: (1) CSS custom properties `--motion-duration-fast/base`, `--motion-easing-standard` (`_motion.scss`), обнуляются под `@media (prefers-reduced-motion: reduce)`; (2) `AltroneApplication` обёрнут в `<MotionConfig reducedMotion="user">` — глобальный эффект для всех анимаций на `motion/react` без правки каждого компонента; (3) `useMediaMatch` для ручного JS-тайминга уже существовал, применять по мере необходимости (сейчас в коде нет ручного `setTimeout` под анимацию — unmount-тайминг уже идёт через `AnimatePresence` самого `motion`).

Разобрал две реальные зацикленные CSS-анимации по WCAG 2.3.3 (не автоматически, решение по каждой подтверждено отдельно): `Skeleton` shimmer — чисто декоративная, остановлена под reduced motion (`animation: none`). `Loading` спиннер — функциональный индикатор состояния (единственный сигнал, что фоновая операция ещё идёт), сознательно оставлен как есть, отмечено комментарием в коде. Добавлена документационная Storybook-история `Foundations/Motion`.

Зачем: reduced motion — это не «выключить всё движение», а убрать декоративное/автоплей/зацикленное, сохранив прямую обратную связь на действия пользователя и функционально значимые индикаторы. Часть архитектурного рефакторинга v4 (`ARCHITECTURE-V4.md`, `.claude/rules/motion.md`), Linear T-169.
